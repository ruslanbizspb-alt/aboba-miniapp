# Заставка (видео под бренд)

Заставка Mini App — короткое видео (≈190 КБ, 3,2 с, H.264), отрендеренное из `stage.html`. Так анимация одинаково плавная на любом телефоне.

```
pip install playwright && playwright install chromium   # нужен и ffmpeg
python3 render.py --accent 6D4AFF --name "Aboba Card" --mark A --out ../../intro
```

Получаются `intro.mp4` и `intro.jpg` (последний кадр — постер на случай, если телефон не дал автозапуск, например в режиме энергосбережения).
Для White Label: рендерить при сохранении бренда в админке и отдавать ссылку на видео бренда (в драфте — параметр `?intro=`).
