# Логотипы сервисов

Положите сюда файл логотипа (лучше SVG, можно PNG) с именем-ключом: `steam.svg`, `esim.svg`, `chatgpt.svg`, `spotify.svg`, `playstation.svg`, `appstore.svg` и т. д. (ключ = название сервиса латиницей, строчными, без пробелов и знаков).

Потом впишите ключ в `LOGOS` в `index.html`, например `const LOGOS={steam:'svg',spotify:'png'};` — иконка заменит монограмму на главной и в каталоге.
